WEBSITE GABUNGAN — PT SAHID UNGGUL MANDIRI

Paket ini menggabungkan website yang kamu unggah dengan modul portofolio Proyek SUM. Konten lama dipertahankan; bagian portofolio baru ditambahkan sebelum bagian Kontak.

CARA MENJALANKAN
1. Ekstrak seluruh ZIP ke satu folder.
2. Buka folder tersebut di VS Code.
3. Jalankan index.html dengan Live Server.
4. Jangan pisahkan folder portfolio-assets, images, atau documents dari file utama.

FILE UTAMA
- index.html: halaman website gabungan
- style.css dan script.js: file website asli yang kamu kirim
- portfolio.css dan portfolio.js: tampilan dan interaksi portofolio baru
- portfolio-assets/: 26 gambar dokumentasi
- logo.jpeg dan images/favicon.png: logo
- documents/: dokumen legalitas yang disertakan

- Materi proyek ditampilkan sebagai dokumentasi/as-built/visualisasi sesuai arsip. Paket tidak mengklaim perusahaan sebagai pelaksana proyek karena peran tersebut belum terkonfirmasi.
